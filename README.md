# AI 에이전트 활용 원칙과 방법론

AI를 이용한 작업·탐구·학습에서 참고할 개인적인 원칙과 방법을 정리한다. 특정 모델이나 서비스의 사용법보다 오래 유지할 수 있는 기준에 집중한다.

## 문서

- [원칙](PRINCIPLES.md): 무엇을 지향하고 어떤 판단 기준을 유지하는가
- [방법론](METHODS.md): 목적과 상황에 따라 어떤 접근법을 선택하는가
- [구현](IMPLEMENTATION.md): 이를 실천하도록 환경을 구성하는 일반적인 방식
- [프로필](profiles/): 일부 환경에 적용할 수 있는 선택적인 지침 예시

원칙은 판단 기준, 방법론은 실천 방식, 구현은 이를 가능하게 하는 수단이다. 프로필은 특정 환경에 무엇을 적용할지 선택한 구성이다. 네 구분이 네 개의 독립 시스템이나 필수 절차를 뜻하지는 않는다.

## 사용과 관리

필요한 원칙과 방법만 선택한다. 모든 문서를 매번 에이전트에 전달하거나 모든 방법을 강제하지 않는다.

문서에는 일반적으로 재사용할 내용을 남기고, 특정 프로젝트의 이력·도구 설치법·실험 기록은 포함하지 않는다. 의미 있는 기준이 달라질 때만 수정하며 Git 이력으로 변경을 추적한다. 환경별 지침은 원칙의 원본을 대신하지 않는다.

이 문서는 개인의 활용 기준이지 모든 사용자에게 적용되는 표준을 주장하지 않는다.
