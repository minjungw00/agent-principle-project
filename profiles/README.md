# 프로필 사용 및 설계 기준

`profiles/`는 원칙과 방법론을 **각 환경에서 단독으로 사용할 수 있는 행동 지침**으로 구성한 선택적 템플릿 모음이다. 각 템플릿은 원본 문서나 다른 프로필을 읽지 않아도 의미가 통하도록 작성한다.

## 설계 기준

- **독립성:** 전후 대화, 특정 저장소, 원본 문서에 대한 접근을 필수 전제로 삼지 않는다.
- **범용성:** 특정 모델·언어·프레임워크·도구와 개별 프로젝트의 규칙을 불필요하게 포함하지 않는다.
- **충실성:** 핵심 원칙을 실제 행동으로 표현하되 원칙·방법론 문서 전체를 복제하지 않는다.
- **선택성:** 적용 조건에 맞는 방법만 사용한다. TDD나 특정 문답법 등을 모든 작업에 강제하지 않는다.
- **간결성:** 짧은 공통 지침을 우선하고, 중복·설정 안내·빈 입력 항목으로 기본 지침을 늘리지 않는다.
- **경계:** 지침은 행동을 안내할 뿐, 테스트 결과·장기 기억·승인이나 접근 권한을 보장하지 않는다.
- **확장성:** 실제 환경의 고유 요구사항은 해당 환경에서 별도로 추가한다. 이 템플릿 자체를 변경할 필요는 없다.

## 템플릿

- [`chatgpt.md`](chatgpt.md): 일반적인 채팅용 맞춤 지침. **Instructions** 아래 항목을 단독으로 사용한다.
- [`AGENTS.md`](AGENTS.md): 전역 또는 개별 작업 저장소에 배치할 수 있는 범용 에이전트 지침. 파일 전체를 단독으로 사용할 수 있다.

원본 [원칙](../PRINCIPLES.md)과 [방법론](../METHODS.md)은 템플릿을 작성·검토할 때 참고하는 기준이며, 템플릿 실행 중 반드시 조회해야 하는 의존성이 아니다. 환경이 바뀌었다는 이유만으로 프로필을 갱신하지 않고, 실제 행동 지침에 의미 있는 변경이 필요할 때 수정한다.
